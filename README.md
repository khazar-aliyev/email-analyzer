# Email Parser in Java

A simple Java console application that prompts the user for an email address and extracts the username and domain name using string manipulation methods.

## Features
- Validates if the input contains an `@` symbol.
- Extracts the **username** (everything before `@`).
- Extracts the **domain** (everything after `@`).

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Compile and run `Khazar.java`.
4. Enter an email address when prompted (e.g., `user@example.com`).
